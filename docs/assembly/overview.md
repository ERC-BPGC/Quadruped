# Assembly Guide

This page should become the step-by-step physical build guide. Keep it practical: photos, part names, screw lengths, orientation warnings, and checks after each stage.

## Suggested flow

1. Prepare printed or machined parts.
2. Assemble one leg.
3. Validate joint range and mechanical clearance.
4. Repeat for all legs.
5. Mount electronics and route wiring.
6. Perform no-load motor tests.
7. Perform tethered standing tests.

## Add photos

Use clear photos for each step. If a part can be installed backwards, show the wrong orientation too and label the risk.

# Mechanical Overview

This page should become the mechanical source of truth for our robot: dimensions, CAD files, link geometry, joint layout, fasteners, materials, manufacturing notes, and assembly order.

## Fill this first

- Final CAD location and export formats.
- Exploded assembly screenshots.
- Leg naming convention: front-left, front-right, rear-left, rear-right.
- Joint order and sign conventions.
- Link lengths and offsets used by control code.
- Known weak points, alignment issues, and manufacturing tolerances.

## Useful page structure

1. Architecture and design goals.
2. CAD file map.
3. Bill of materials.
4. Assembly sequence.
5. Known issues and revision ideas.

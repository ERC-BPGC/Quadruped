# Bring-up Guide

Bring-up is where future contributors can break hardware quickly, so this page should be conservative and explicit.

## First draft checklist

- Inspect frame and wiring before applying power.
- Verify battery voltage and polarity.
- Power compute without motor power first.
- Confirm communication with each motor driver.
- Run one motor at low torque or low current.
- Validate joint directions and zero positions.
- Run a single-leg test before enabling all legs.
- Keep the robot supported during first full-system tests.

## What to record

- Commands used.
- Expected output.
- Actual output.
- Photos or videos of the test setup.
- Any thermal, electrical, or mechanical anomalies.
